# 本地规则检查面板

0.4.0 开发版功能，尚未发布到 PyPI。面板只在本机运行，不调用模型。
无需编写 Python 测试；安装本项目后，通过浏览器配置规则和查看任务。

## 启动

在当前开发分支目录安装，然后切到要检查的项目目录：

```console
python -m pip install .
pytest-codex-panel --project .
```

也可使用 `python -m pytest_codex.dashboard --project .`。
浏览器会自动打开。保留终端窗口，按 Ctrl+C 关闭服务。
`--no-browser` 只打印本地链接；`--port 0` 自动选空闲端口。

启动命令表示允许面板只读查找**指定项目**的近期会话。默认检查
`$CODEX_HOME/sessions`，未设置时为 `~/.codex/sessions`。
不读取 auth.json、全局配置或个人全局 AGENTS.md。

```console
pytest-codex-panel --project /path/to/project --sessions /path/to/codex/sessions --limit 20
```

面板读取最新 500 个日志的首行元数据，只解析 cwd 与项目目录匹配的日志，
每个匹配会话只解析一次，再按任务开始时间选取最近 20 次（可选 1–100 次）。
没有时间的任务按日志更新时间排序并标注未知；较早日志可能未扫描。
格式错误、不兼容或不可读的日志会显示提示，不算作通过。
目录与文件的符号链接／重解析点不会被跟随。项目只有根目录 AGENTS.md 会被展示；
嵌套目录规则不会自动合并。

## 查看任务

- **命令**：查看命令片段和退出码。只有开始记录时退出码未知，仍参与禁令命中检查。
- **文件报告**：显示日志声称发生的 FileChange 路径，不能证明实际写入成功，也可能漏掉 shell 改动。
- **用量**：显示缓存输入、非缓存输入和输出；非缓存为总输入减缓存输入。
  仅使用归属本轮的最后一份完整累计计数，缺字段时显示 `—`，不当作零费用。
- **详情**：点击任务查看命令、命中证据、文件报告、MCP 工具名和观察范围缺项。
  面板不发送用户提问、推理、最终回复、命令输出或 MCP 参数／结果。

“已完成”是历史会话完成状态，不等于任务验收通过，也不是一次新的模型试验。

## 不写代码地检查规则

在右侧输入每行一条规则，点击“应用并检查”：

```text
禁用命令片段：
pip install
npm install

禁改路径模式：
legacy/*
.env
```

命令按文本片段匹配，忽略大小写和连续空白，不进行完整 shell 语义分析；
路径按大小写敏感的 glob 匹配相对项目路径。模式文字只用于匹配，不会执行。

展开 AGENTS.md 可查看本项目规则。“填入候选禁令”只识别少量明确句式，
例如 `Never run` 加反引号命令、`不要修改` 加反引号路径。
候选需核对后再点“应用”；条件例外、嵌套规则与其他自然语言要求不会被自动理解。
规则仅保存在当前服务进程内存，关闭后清除，不修改 AGENTS.md。

| 颜色 | 含义 |
| --- | --- |
| 红色 | 已观察的命令片段或文件报告命中配置的禁令。文件命中仍是日志报告证据。 |
| 绿色 | 仅已配置的命令规则通过，且命令观察范围完整；不是“全部 AGENTS.md 均遵守”。 |
| 黄色 | 未配置规则、日志／展示范围不完整，或文件报告不足以证明没有改动。 |

每项任务最多展示 100 条命令（每条 2,000 字符）、500 个路径和 100 个 MCP 调用。
截断时保持未知，不以未展示内容的缺失判通过。

## 回归对比

切到“回归对比”，选择两份通过 `--codex-results` 生成的 JSON，并选择唯一变化因素。
沿用 compare.py 的输入、验收器、环境和模型／CLI 匹配检查；不接受桌面历史观察或
回放记录冒充真实新样本。有执行错误、验收器错误或跳过时保留“无法判定”。
两份结果总大小需小于 4 MiB，只发送到本机服务，不保存到磁盘；通过率不是模型排名，
Token 计数也不是 API 账单。原有原始报告仍由用户自行保管。

## 本地数据边界

服务只绑定 127.0.0.1，使用每次启动随机生成的访问能力链接，API 同时检查
Host、Origin 和访问令牌。没有 CORS、外部 CDN、遥测或模型请求。
不要分享完整启动链接；不要通过代理或端口转发公开服务。
界面文本使用 textContent 渲染，日志中的 HTML 或命令不会被执行。

项目／home 路径及常见凭据格式会做替换，但这不是完整的保密信息识别器。
命令和本项目规则仍可能含私人文字，截图或分享前请检查。验收截图全部使用合成数据。
